# Amazon Clone | E-Commerce Homepage

A static, Amazon-inspired e-commerce homepage developed using **HTML5 and CSS3**. This project focuses on recreating the visual structure, navigation, product sections, and overall layout of a popular e-commerce platform through frontend development.

## Live Demo

[View Live Website](https://sagnikagoswami.github.io/Amazon-Clone/)

## Features

- Amazon-inspired navigation bar with logo, search interface, and shopping cart layout
- Promotional banner and homepage sections
- Product and category cards with images
- Horizontal product display sections
- CSS-based hover effects and visual styling
- Structured page layout using HTML and CSS Flexbox

## Technologies Used

- **HTML5:** Page structure and content
- **CSS3:** Styling, layouts, and hover effects
- **CSS Flexbox:** Alignment and arrangement of interface elements
- **Font Awesome:** Icons used throughout the interface

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/SagnikaGoswami/Amazon-Clone.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Amazon-Clone
   ```

3. Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## Project Scope

This project is a **frontend UI recreation** developed to practice HTML, CSS, page layouts, and interface styling.

It does not include backend functionality, user authentication, payment processing, or a functional shopping cart. Elements such as the search bar and cart are included for visual representation.
